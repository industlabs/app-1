# Industrial Landing Builder v12 - Visual Style Frameworks

This version is built from the previous working package and adds a visual landing page style system.

## New in v12
- Visual Landing Page Editor now includes Page Style controls.
- Select landing page frameworks without editing CSS.
- Built-in framework templates: Industrial Dark, Clean Light, Premium Yellow Accent, Modern Blue Utility, and White Card B2B.
- Built-in color palettes: Pinnacle, Utility Blue, Energy Green, and Steel Gray.
- Visual controls for CTA color, dark color, background, font, button radius, card radius, and hero height.
- Template buttons in the editor: Pinnacle Template, Clean Template, and Premium Template.
- Published pages now receive template classes and CSS variables automatically.
- Previous features retained: campaigns, keywords, variable categories, visual editor, media picker, favicon, form builder, popup form button, hero form placement, project gallery, icon grid, optional links, reports, and publishing.
